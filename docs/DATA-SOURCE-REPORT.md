# تقرير مصدر بيانات Instagram

## النتيجة التنفيذية

تم تثبيت **Instaloader 4.15.3** وتشغيل اختبار فعلي على الحساب العام `instagram` بتاريخ 2026-09-19. تمكنت المكتبة من بدء الاتصال، لكن Instagram أعاد استجابة **HTTP 429 Too Many Requests** من نقطة `web_profile_info`، لذلك لا يمكن اعتبار Instaloader مصدرًا موثوقًا دائمًا أو أساسًا وحيدًا للإنتاج.

## ما أمكن التحقق منه

| العنصر | الحالة |
| --- | --- |
| تثبيت المكتبة | نجح |
| إصدار المكتبة | 4.15.3 |
| بدء الاتصال بالمصدر | نجح |
| استلام بيانات profile كاملة | لم يحدث بسبب 429 |
| التعامل مع الخطأ | تم التقاطه وتسجيله بدون كسر التطبيق |

## الحقول التي يدعمها تصميم المزود

يدعم العقد البرمجي الحقول التالية عندما يوفرها المصدر: `username`, `userid`, `full_name`, `biography`, `followers`, `following`, `posts_count`, `verified`, `private/public`, `profile_picture`, `external_url`، ووقت الجلب. جميع حقول المصدر اختيارية حتى لا يفترض التطبيق أن Instagram يعيد شكلًا ثابتًا.

## مصفوفة الحالات

- اسم مستخدم غير موجود: يتوقع `ProfileNotExistsException` أو استجابة تعادلها.
- حساب خاص: قد تتوفر الحقول العامة الأساسية، مع حفظ `isPrivate=true` وعدم محاولة تجاوز الخصوصية.
- Rate limit أو حظر: قد يظهر `429`, `TooManyRequestsException`, `LoginRequiredException` أو `ConnectionException`.
- خطأ شبكة: `ConnectionException` أو timeout.
- تغير شكل الاستجابة أو نقص البيانات: تحويل الحقول غير المتاحة إلى `null` وتسجيل خطأ المزود.

## القرار المعماري

لم يتم ربط الواجهة مباشرة بـ Instaloader. يوجد `InstagramProvider` abstraction، و`ProviderManager`، و`InstaloaderProvider` يتصل بعامل Python منفصل عبر HTTP. يوجد `MockProvider` للتطوير المحلي فقط، ولا يتم اختياره في الإنتاج إلا إذا تم ضبط `INSTAGRAM_PROVIDER=mock` صراحة مع `NODE_ENV=development`.

## القيود

Instaloader يعتمد على واجهات Instagram العامة غير الرسمية، وقد تتغير أو تتطلب جلسة مصادق عليها أو تتعرض لتحديد المعدل. المنصة لا تطلب كلمات مرور Instagram ولا Cookies ولا Sessions ولا Access Tokens، ولا تحاول الوصول للحسابات الخاصة أو تجاوز الحماية. يجب وضع عامل Python خلف عملية تشغيل منفصلة، مع cache وrate limits وbackoff وعدم الفحص المتوازي.

## البديل المقترح

للاستخدام التجاري المستقر، يوصى بإضافة موفر رسمي أو شريك بيانات مرخص عند توفر الصلاحيات المناسبة. التطبيق جاهز لتبديل المزود دون تغيير الواجهة أو قاعدة البيانات. في حالة استمرار 429، يعرض النظام رسالة عربية مفهومة، ويحافظ على آخر Snapshot صالح بدل حذف البيانات أو عرض بيانات وهمية.
